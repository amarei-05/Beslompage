# BesLom

명일방주 기반 OC, Lom · Besprebel 프로필 페이지.

## 파일
- `index.html`, `main.js`, `style.css` : 페이지
- `data.js` : 캐릭터 정보 (내용은 이 파일만 고치면 됨)
- `images/` : 전신·두상 이미지
- `voices/` : 대사 보이스

## GitHub Pages로 올리기
1. 새 저장소(public) 만들기
2. 이 폴더 안의 파일과 폴더를 전부 업로드 (Add file → Upload files, 폴더째 끌어다 놓기)
3. Settings → Pages → Branch `main`, 폴더 `/ (root)` → Save
4. 1~2분 뒤 `https://<아이디>.github.io/<저장소이름>/` 에서 확인
